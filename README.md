<h3 align="center">Land of the Divided: A Hearts of Iron IV Total Conversion Mod</h3>

  <p align="center">
    The premise of the scenario is a (not strict) reverse of the Cold War, where the United States "loses" the Cold War through economic and military mishaps, and as a result the Soviet Union reigns victorious. Following such turmoil in the United States, conservative (and more radical) forces conspire in the National July 4th Movement (akin to the August Coup) to capture Clinton after his victory in the 1996 election. As a result, military, Movement, federal, and state forces clash, with no decisive winner, resulting in a frozen conflict until the start date where the American Spring has led to many highly successful revolts, forcing nations to build up and remilitarize again.

## Getting Started

This is a Hearts of Iron IV mod, so it requires the Hearts of Iron IV game to be nstalled to run, and won't be able to run in the web. Otherwise, it doesn't require anything else.

### Installation

1. Clone the repo to the `Documents/Paradox Interactive/Hearts of Iron IV/mod/` folder
   ```sh
   git clone https://github.com/chardynamics/landofthedivided.git
   ```
2. Create a `.mod` file in the `/mod` directory with a path to the mod repository (copy the `descriptor.mod` file in the directory to the `/mod` directory, then adding this line:)
    MacOS:
   ```
   path="/Users/[username]/Documents/Paradox Interactive/Hearts of Iron IV/mod/landofthedivided"
   ```
3. Load up Hearts of Iron IV, and in Paradox Launcher add the mod to your playlist and activate and run, with no other mods installed!
